# Game-live

Небольшой браузерный прототип трекера "Игра Жизни".

Теперь приложение сохраняет параметры на сервере.

## Запуск

1. Установите Node.js (уже присутствует в большинстве сред).
2. Запустите сервер командой:

   ```bash
   node server.js
   ```

3. Откройте в браузере `http://localhost:3000`.
